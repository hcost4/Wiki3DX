# Gerador de Wiki 3DX

Widget interno SKA + GoEngineer para criar a Wiki de implantação 3DEXPERIENCE na comunidade do cliente.

- `index.html`: casca fixa usada no Run your App (não muda)
- `app.js`: widget (atualizado a cada versão)
- `logo.png`: logo SKA + GoEngineer

Usa a sessão do usuário logado na 3DEXPERIENCE. Não guarda senha nem dados de cliente.
